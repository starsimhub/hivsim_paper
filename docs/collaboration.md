# Involving other HIV modellers (v0.2)

**Framing:** validated models agree on what is observed and disagree on what isn't. HIVsim tests which answers the data actually pin down. It does not replace anyone's model, and it ranks none. Other groups' validation work supports the premise.

**Principles**
1. Switches are described by mechanism, never as "model X". Any table mapping switches to named models is reviewed by those groups before it appears anywhere.
2. Other groups take part in the parts where their judgement matters most:
   - reviewing the switch descriptions;
   - writing benchmark questions and reference answers;
   - blind grading of the harness.

   Each contributor is credited as a co-author or by name in the acknowledgements, whichever they prefer.
3. No winner language, in the paper, talks or preprints.
4. Everything is open: the menu, harness, benchmark and attribution analyzer.
5. People get no surprises. Anyone whose model's published results are compared in R2 sees those comparisons before submission.

**When**
- **Sprint 1, week 7:** shortlist the graders and reviewers. Optima is ours; the rest are your call.
- **Sprint 2, week 1:** send invitations.
- **Sprint 2, weeks 4–5:** grading.
- **22 Feb – 19 Mar:** co-author round.

**HIVMC** (the multi-model plugin) is set aside for a later, separate project. It would need agreement from each model group up front.
